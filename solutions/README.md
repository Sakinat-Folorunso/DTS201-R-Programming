# Solutions (lecturer copies)

Complete worked solutions for every notebook. The subtitle of each file ends with "SOLUTIONS (lecturer copy)".

This folder is the **source**: edit here, then run `Rscript scripts/build_starters.R` to regenerate `notebooks/`. Task code sits between `# >>> SOLUTION` and `# <<< SOLUTION` markers (written answers between `<!-- >>> SOLUTION -->` and `<!-- <<< SOLUTION -->`).

If you publish the repository for students, remove this folder (or keep it in a private branch) until assignments are marked.
