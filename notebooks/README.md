# Notebooks (student starters)

R Markdown (`.Rmd`) practicals for DTS 201, Weeks 0–11, plus the EDA template. Each file has the full explanation and worked examples; the task code is blank (`# TODO`) for you to complete.

**How to use**
1. Open `DTS201_R.Rproj` in RStudio (so the `data/` paths work).
2. Open a notebook from this folder.
3. Run chunks with Ctrl/Cmd + Enter, or click **Knit** to produce an HTML report.

Do Week 0 first. Run Week 2 before Weeks 3 and 11 (it writes the cleaned data they use).
